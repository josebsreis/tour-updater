# Tour Updater

Replace, rename, reorder or add the rooms of a tour exported by Tour Studio,
then download the updated tour as a zip, ready to upload.

Open https://josebsreis.github.io/tour-updater/, drag in the tour folder, make
the changes, press **Make the updated tour**. Everything runs in the browser
on your own computer — no file is uploaded anywhere.

New panoramas: a square top-bottom picture (left eye on top) gives 3D in VR and
the flat view on screen; a 2:1 picture gives a flat room. Tiles are made at the
tour's own JPEG quality, at full resolution, the same way Tour Studio exports.
